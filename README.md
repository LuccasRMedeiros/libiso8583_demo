# libiso8583_demo

This project demonstrates how a POS machine could behave when executing a
transaction.

## Building

The project is divided into "lib", "pos" and "unit_tests". Both "pos" and 
"unit_tests" depends on "lib". So to ease the building process you can use the
main Makefile (from the project root) to build each submodule; it have four
rules: all, debug, clean, re

### all

```
make all
```
By running the "all" rule, it will build the "lib", then builds "unit_tests" and
run them, only going to build "pos" if all tests passes.

### debug

```
make debug
```
If you need to build each piece anyway, you can use "debug" rule. It will
generate "lib", "unit_tests" and "pos" (in order), but won't run "unit_tests"
and add debug symbols to every part generated, so it can also be easily
debugged.

### clean 

```
make clean
```
It will clean every artifact generated by the Makefiles recipes.

### re 

```
make re 
```
Clean the project (like in "clean" rule) and rebuild all (like in "all" rule).

## Running 

Both "unit_tests" and "pos" yield binary files: "pos_demo_unit_tests" and
"pos_demo" respectively. You will find the unit tests binary inside the 
"unit_tests" folder, the "pos_demo" will be placed in the project root folder.
None needs extra arguments to be executed.

## Using the library

The library is composed by four headers: iso8583_demo.h, luhn_validation, 
memory.h and stt_machine.h; each responsible to work on a important part of the
process.

### iso8583_demo.h 

Takes care of building and parsing iso8583 messages.

#### Module functions:
```
iso8583msg_ret_e iso8583_buildmsg(iso8583msg_st msgfields, size_t buf_len, unsigned char *buf_out, size_t *out_len);
```
Build an iso8583 message, storing the result in buf_out and its length in 
out_len.
    **msgfields:** Instance of struct iso8583msg_st with the desired DEs and 
message it is necessary to clean the struct instance ***before*** filling the 
required fields.
    **buf_len:** The total space in "buf_out", be aware that values mismatching
the buffer total size may cause invalid access to memory.
    **buf_out:** A buffer to receive the built message, the bytes will be stored
raw 
    **out_len:** The amount of bytes writen to "buf_out"
Return MSG_OK on sucess, or an descriptive error code accordingly to the
iso8583msg_ret_e values.

```
iso8583msg_ret_e iso8583_parsemsg(unsigned char *msg, iso8583msg_st *out);
```
Attempt to parse an iso8583 message stored in raw bytes.
    **msg:** An array of bytes to be parsed into an iso8583msg_st instance.
    **out:** A pointer to the instance where the message will be parsed to.
Return MSG_OK on sucess, or an descriptive error code accordingly to the
iso8583msg_ret_e values.

#### Module types:
```
iso8583msg_ret_e
{
    MSG_OK (0),
    MSG_BUFFER_TOO_SHORT (1),
    MSG_TYPE_NOT_PRESENT (2),
    MSG_CANNOT_BE_NULL (3),
	MSG_OUT_LEN_CANNOT_BE_NULL (4),
    MSG_STRUCT_OUT_CANNOT_BE_NULL (5),
}
```
Return codes.

```
iso8583msg_st
{
    msgtype: fixed size array of 5 bytes; stores the MTI message type
    de002_pan: fixed size array of 20 bytes; stores the card pan
    de003_procde: fixed size array of 7 bytes; stores the process code
    de004_amount: fixed size array of 13 bytes; stores the transaction amount
    de007_datetime: fixed size array of 11 bytes; stores transaction date
    de011_stan: fixed size array of 7 bytes; stores the System Trace Audit Number
    de012_loctime: fixed size array of 7 bytes; stores transaction local time
    de037_refnumber: fixed size array of 13 bytes; stores the retrival reference number
    de041_cardid: fixed size array of 9 bytes; stores the card acceptor terminal identification
    de049_currency: fixed size array of 4 bytes; stores the currecy code
    de128_authcode: fixed size array of 65 bytes; stores the authentication code
}
```

### luhn_validation.h

Pan validation functions

#### Module functions:
```
luhn_validation_e luhn_validatepan(char *pan);
```
Apply the modulo 10 formula to validate a pan 
    **pan:** The card pan in string format to be checked
Return LUHN_VALIDATION_OK for a valid pan, LUHN_VALIDATION_NULL_PAN for a null 
argument to "pan", LUHN_VALIDATION_DIGIT_NOT_CHECK for invalid pan.

#### Module types:
```
luhn_validation_e
{
    LUHN_VALIDATION_OK (0),
    LUHN_VALIDATION_NULL_PAN (1),
    LUHN_VALIDATION_DIGIT_NOT_CHECK (2),
}
```
Return codes.

#### Module functions:
```

int memory_get_str_filename(byte *dir_filename, char *out);
int memory_read(memory_dir_st **out);
int memory_read_file(const char *filename, byte **out);
void memory_show_info(void);
``` 

#### Module types:
```
byte
```
Alias to "unsigned char"


```
memory_dir_st (packed)
{
    filename: fixed size array of 64 bytes; stores the filename
    block_in: metadata; block where the file is stored
    file_size: metadata; file total size in bytes
    datetime_created: metadata; when the file was created in memory
}
```
